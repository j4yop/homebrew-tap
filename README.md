# Arrowslit Homebrew tap

```bash
brew trust j4yop/tap
brew install --cask j4yop/tap/arrowslit
```

Or as one line:

```bash
brew trust j4yop/tap && brew install --cask j4yop/tap/arrowslit
```

Homebrew 7 requires trusting a third-party tap once before it will load the cask.

Arrowslit is a local-only productivity nook for the MacBook notch.
Source and releases: https://github.com/j4yop/arrowslit
